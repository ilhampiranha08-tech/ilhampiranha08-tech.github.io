01 // CORE SYSTEM CAPABILITIES

6 Pilar Fitur Utama Vortex

⚡

Super Fast Explorer with Dual Pane

Navigasi dua folder atau media penyimpanan secara berdampingan dalam satu layar. Memindahkan berkas besar, membandingkan isi direktori, dan menyalin data menjadi instan tanpa perlu bolak-balik aplikasi.

🔒

AES-256 Safe Folder Encryption

Brankas berkas rahasia terenkripsi simetris AES-256-GCM. Kunci kriptografi diamankan langsung oleh chip perangkat keras Android Hardware Keystore. Privasi dokumen dan foto penting terlindungi 100% di level hardware.

📡

WebDAV/FTP Server & P2P Near-Drop

Ubah smartphone menjadi server file nirkabel lokal. Kelola dan unduh seluruh file di HP dari peramban web laptop atau PC Windows/Mac/Linux tanpa kabel data. Dilengkapi transfer peer-to-peer instan via Wi-Fi Direct.

🌐

SMB / FTP / SFTP / WebDAV Client

Klien protokol jaringan all-in-one. Terhubung langsung ke NAS (*Network Attached Storage*), shared folder Windows (SMB), server Linux jarak jauh melalui enkripsi SSH (SFTP), dan server cloud WebDAV secara terpadu.

📝

Text Editor with Undo/Redo

Editor teks dan kode sumber bawaan yang ringan namun andal. Dilengkapi penomoran baris, fitur Undo & Redo tanpa batas, pencarian cepat, dan dukungan multi-format untuk membaca serta mengedit kode langsung di perangkat.

🧹

Storage Analyzer & Smart Clean-Up

Visualisasi interaktif penggunaan memori internal dan kartu SD. Menganalisis file-file berukuran raksasa, file residu yang terlupakan, folder sampah, dan duplikasi berkas agar ruang penyimpanan tetap lega dan optimal.

02 // ARCHITECTURE & ENGINEERING

Dirancang untuk Kecepatan, Keamanan & Nol Iklan

Vortex bukan sekadar file explorer biasa. Dibangun dari nol oleh Ilham Sugiri dengan filosofi keandalan tingkat Linux pada perangkat Android modern.

  • ✔
    Virtual File System (VFS) Modular: Mengabstraksi Local Storage, SAF, USB OTG, NAS SMB, FTP, SFTP, dan WebDAV ke dalam satu unified I/O stream berkinerja tinggi.
  • ✔
    Zero-Telemetry & 100% Ad-Free: Tidak ada SDK iklan, pelacak perilaku, analitik invasif, ataupun server relai perantara. Seluruh lalu lintas data berjalan langsung titik-ke-titik (P2P).
  • ✔
    Reactive Kotlin Coroutines & Jetpack Compose: Antarmuka modern yang sangat mulus pada layar 120Hz tanpa freeze saat membaca jutaan file sistem.
  • ✔
    Integrasi Cloud OAuth Aman: Dukungan Google Drive dengan protokol autentikasi token resmi tanpa menyimpan password pengguna.
