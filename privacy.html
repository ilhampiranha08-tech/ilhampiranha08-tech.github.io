Privacy Policy

Application: Vortex: File Manager (Vortex: File Server & Client)
Last updated: October 8, 2026
Developer: Ilham Sugiri (Indonesia)

1. Data Collection & Privacy Principles

Vortex: File Manager does NOT collect, harvest, store, or transmit any personal data.

  • ❌ No Analytics or Telemetry (No Firebase, Google Analytics, or third-party trackers).
  • ❌ No Advertising SDKs (100% Ad-Free).
  • ❌ No User Registration or accounts required.
  • ❌ No External Server Relays (All transfers run locally or direct P2P).

2. Google API Services Compliance (Google Drive)

Vortex requests the Google Drive scope (https://www.googleapis.com/auth/drive) solely to allow users to view their files, upload selected items, and download cloud files directly inside the application. Vortex adheres strictly to the Google API Services User Data Policy, including the Limited Use requirements. Your tokens are stored securely in encrypted private app storage and are never shared.

3. Permissions Justification

  • MANAGE_EXTERNAL_STORAGE: Required to organize files, browse local storage, and host local servers.
  • INTERNET: Required for local server protocols (FTP/SFTP/WebDAV/DLNA) and official cloud API connections.
  • NEARBY_WIFI_DEVICES / LOCATION: Required by Android OS exclusively for Wi-Fi Direct peer discovery in Near-Drop transfers. Physical location is never accessed or stored.
